## Lab Activity 5: Discussion

- **Workflow (DummyJSON vs Firebase)**: DummyJSON provides a mock authentication flow where an API returns a static token that we store in `SharedPreferences`. Firebase Authentication provides real, secure backend infrastructure. The signup screen uses Firebase's `createUserWithEmailAndPassword`, creating persistent records in the cloud, while DummyJSON only mocks login responses.
- **UserService Idea**: The `UserService` class acts as a single repository abstracting both the local storage logic (for DummyJSON) and the cloud identity logic (for Firebase). It manages token storage, session clearing on logout, and profile manipulation.
- **Firebase Benefits**: Firebase brings robust security rules, actual user persistence, token refreshing, and built-in methods for account recovery, deletion, and profile updates that are fully functional in a production environment compared to a mock API.
